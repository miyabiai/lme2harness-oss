# コピペで移行（コマンドを打たない手順）

コマンドは打ちません。**Claude Code か Codex のチャット欄に、下のメッセージを順番に貼って送るだけ**です。

各メッセージの右上にある **コピーボタン** を押して、チャット欄に貼り付けて送ってください。AI が作業を進めて、あなたにしてほしいことがあるときだけ声をかけてきます。

| 順番 | 貼るメッセージ | あなたがやること |
|---|---|---|
| ① | 準備 | L Harness の API キーを、AI が開いたファイルに貼る |
| ② | エルメにログイン | ブラウザでエルメにログインして「許可」を押す |
| ③ | 移行 | 「何が移るか」の表を見て「OK」と送る |
| ④ | 並行運用 | 秘密の値を2つ貼り、エルメの「Webhook転送」画面に URL を2つ貼る |
| ⑤ | 切り替え | 画面での操作を、AI の案内どおり1つずつ |
| ⑥ | 後片付け | 消すものを見て「OK」と送る |

## 始める前に用意するもの

- **L Harness のセットアップが終わっていること**（`create-line-harness` を最後まで終えた状態）
- **L Harness の API キー**（セットアップ完了画面に一度だけ出る「API Key」）
- **エルメにログインできること**（メールアドレスとパスワード）
- **Claude Code か Codex**（パソコンで動かすもの）

---

## ① 準備

```text
エルメ（L Message）から L Harness へ移行したいです。https://github.com/miyabiai/lme2harness-oss のツール「lme2harness」を使います。
私はコマンドを打てないので、全部あなたが実行してください。
1. 作業用のフォルダ「lme-migration」を作り、上のリポジトリを取ってきて、README と docs/手順書.md を読んでください（npm にはまだ公開されていないので、取ってきて組み立ててから使ってください）
2. lme-migration の中で init を実行してください
3. L Harness の API キーは私が貼ります。.env をテキストエディタで開いて、どの行に貼ればいいか教えてください。キーの値はチャットに書かせないでください
貼り終わったら私が「貼った」と送ります。
```

**あなたがやること**：開いたファイルの `HARNESS_API_KEY=` の後ろに API キーを貼って保存し、「貼った」と送る。

---

## ② エルメにログイン

```text
次に login を実行して、エルメのログイン画面をブラウザで開いてください。
私がログインして「許可」を押すまで、最大5分待っていてください（待つ処理なので、途中で止めないよう裏で動かしてください）。
終わったら doctor で点検して、✗ があれば、私にしてほしいことを1つずつ教えてください。
```

**あなたがやること**：ブラウザでエルメにログインして「許可」を押す。点検で Cloudflare へのログインを頼まれたら、同じようにブラウザでログインする。

---

## ③ 移行

```text
migrate を実行してください。
書き込む直前で止まるので、out/report.md の中身（何が移って、何が移らないか）を、やさしい言葉の表にして見せてください。
私が「OK」と送ったら、--yes を付けて続きを実行し、最後の照合まで終わらせてください。
```

**あなたがやること**：表を見て「OK」と送る。友だちが1万人なら、取り出しに30分くらいかかります。

---

## ④ 並行運用（切り替えの日まで、エルメと L Harness を両方動かす）

```text
切り替えの日まで、エルメと L Harness を並行で動かしたいです。
先に、LINE のチャネルシークレット（LINE Developers の Messaging API チャネルにある値）を私が .env に貼ります。貼る場所を開いて教えてください。
私が「貼った」と送ったら、bridge --deploy を実行して、エルメの「Webhook転送」画面に貼る URL を2つ出してください。
どこに何を貼るか、画面の順番どおりに教えてください。この URL は人に見せてはいけない秘密なので、扱いに気をつけてください。
私が URL を貼り終えたら、「L Messageデータ転送」の署名シークレットを .env に貼る場所も開いて教えてください。貼り終えたら、もう一度 bridge --deploy を実行してください。
```

**あなたがやること**：LINE のチャネルシークレットを `.env` に貼る → エルメ管理画面の「Webhook転送」に URL を2つ貼って有効にする → 署名シークレットを `.env` に貼って「貼った」と送る。

## ⑤ 切り替え（切り替えの日に）

```text
今日、エルメから L Harness に切り替えます。README の「4. 切り替え」の順番で進めてください。
コマンドでできるところはあなたが実行してください。
私が画面で操作するところ（エルメの配信停止、LINE Developers の Webhook URL の変更など）は、1つずつ手順を教えて、私が「できた」と送るのを待ってから次に進んでください。
```

**あなたがやること**：AI の案内どおりに、画面の操作を1つずつやって「できた」と送る。ステップ配信の予定が入っていない時間帯にやってください。
